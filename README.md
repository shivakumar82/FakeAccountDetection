# FakeAccountDetection

AI-Based Fake Social Media Account Detection System

## Project Overview

This project uses Machine Learning to identify potentially fake social media accounts.

## Features

- Individual account analysis
- Fake account risk scoring
- Explainable warning indicators
- Moderator review dashboard
- Coordinated account detection

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- NetworkX
- Plotly
